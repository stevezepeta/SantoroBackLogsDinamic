### 1. "¿Eva realmente usa IA o es solo marketing?"

### 2. "¿Qué pasa si mi sistema ya tiene logs en Elasticsearch/AWS CloudWatch?"
**R:** ¡Perfecto! Eva se integra fácilmente — no reemplaza, complementa. Seguimos leyendo de donde estés almacenando logs actualmente.

### 3. "¿Funciona para sistemas legacy (viejos)?"
**R:** Sí. Solo necesitamos que tu sistema pueda enviar logs vía API REST o escribir en archivo. Tenemos conectores para COBOL, AS/400, etc.

### 4. "Mi equipo no habla inglés — ¿Eva funciona en español?"
**R:** 100% español nativo. Eva responde, alerta y reporta en español mexicano. Multi-idioma viene en Q4 2026.

### 5. "¿Qué pasa si queremos cancelar?"
**R:** Cero ataduras. Cancelas cuando quieras, exportas todos tus datos, y listo. Sin multas ni letras chiquitas.

### 6. "¿Eva puede predecir CUALQUIER fallo?"
**R:** No es mágica — predice basado en patrones históricos. Si es la primera vez que pasa algo, no lo predice (pero sí aprende para la próxima). Precisión actual: 94.2%.

### 7. "¿Cuántos clientes tienen ya usando Eva?"
